# 查询过敏源

这是一个食物不耐受查询工具，用于记录和管理个人的食物 IgG 检测结果。

## 功能特性

- 📋 90 项食物 IgG 检测数据查询
- 🔍 按类别和食物名称搜索
- 📝 记录进食后的反应观察
- ☁️ 支持云端数据同步（JSONBin.io）
- 👨‍👩‍👧‍👦 家人共享同一份数据

## 使用方法

### 首次使用

1. 访问网站后，根据配置面板提示：
   - 打开 [jsonbin.io](https://jsonbin.io) 注册免费账号
   - 获取 API Key 和创建 Bin ID
   - 填入配置保存

2. 搜索食物查看检测结果和饮食建议
3. 记录进食后的观察反应

### 本地使用

点击「暂时跳过」可仅在本地浏览器使用，不同步到云端。

## 技术栈

- 原生 HTML/CSS/JavaScript
- 使用 Tabler Icons 图标库
- JSONBin.io 作为数据存储后端
